# カウントダウン管理

テスト、旅行、行事などの予定までの残り日数と時間を管理する静的Webアプリです。

## 機能
- 複数予定の追加・編集・削除
- 残り日数・時間・分・秒のリアルタイム表示
- 予定中・終了済み・すべての絞り込み
- メモとテーマカラー
- localStorage保存
- JSONバックアップの書き出し・読み込み
- 終了済み予定の一括削除
- PC、タブレット、スマートフォン対応

## 公開方法
1. GitHubで `countdown-manager` というPublicリポジトリを作成します。
2. 4ファイルをアップロードします。
3. Settings → Pagesでmainブランチのrootを公開します。
